    Everything above runs on this device — audio, transcription, and storage never leave your
    browser tab. The one-time model download (~250 MB) is cached afterward for offline use.
  


  

    More on how this works, and known limits
    

      Long recordings. Audio over 15s is split into overlapping windows so nothing
      gets cut off, and matching text at each seam is trimmed to avoid repeats.
      


      Language. Auto-detecting "any of 99 languages" proved unreliable, so LOOB
      asks you to name the language(s) instead — each window is transcribed once per language you
      set, and the result that actually matches that language is kept. This means two languages
      takes twice as long to process as one. It can't catch a language switch faster than ~15
      seconds, or a third, unlisted language. Occasional stuck-word repetition on quiet audio is a
      known Whisper quirk; a couple of safeguards reduce it but can't rule it out entirely. Speed
      depends on your device — WebGPU-capable laptops are notably faster than CPU-only. There's no
      speaker separation yet.
      


      Where entries live. Saved entries — transcript, edits, notes — are stored in
      this browser's IndexedDB for this site only. Clearing site data, or an incognito window,
      removes them; they don't sync across devices. Raw audio is never saved with an entry — download
      it right after recording if you want to keep it, since it's discarded once you record again.
      


      AI reflection (Library → open an entry). Runs via
      Ollama on your own machine,
      never a third-party API. Install it, pull a model (ollama pull llama3.3), then
      start it with this origin allowed:
      


      OLLAMA_ORIGINS=http://localhost:8080 ollama serve
      


      Swap in whatever address you're serving this file from. A "not reachable" badge usually means
      that origin doesn't match — check the browser console for specifics. On phones, use the
      built-in on-device model instead; reaching a desktop Ollama server from a phone needs extra
      network setup (LAN IP, HTTPS) that's easy to get wrong.

              Generates a short reflective response to this entry. Runs in your browser tab via
              WebLLM when your browser supports it (nothing sent anywhere, not even to
              localhost) — otherwise falls back to a model running locally via Ollama.
              This and the optional Myth-scan below are the only features in LOOB that use either of
              these; everything else stays fully offline. Each reflection below can become its own
              thread — reply by typing or by recording a short voice note, then ask for another AI
              response to keep sitting with it.

Myth vs Truth Rule-based · on-device

            

              Scans your transcript for limiting-belief language — absolutist phrasing
              ("always"/"never"), self-blame, catastrophizing, and "should" statements — and quotes
              each match verbatim as a Myth. No AI call, no network request; this runs entirely
              as pattern-matching in your browser, the same way tag suggestions do. The rule list is
              English-only — for other languages, or anything the rules miss, use the optional scan
              below, which uses the same AI engine (in-browser WebLLM, or Ollama as a fallback) as
              AI reflection above.
